# 역할표 — RACI (ruya 시운전)

> 3개 조직 × 주요 시운전 업무의 책임 분담표입니다. 아래 표의 글자는 **플레이스홀더**이며, 실제 프로젝트 합의에 따라 조정하세요.

## RACI 표기

| 기호 | 의미 | 설명 |
| --- | --- | --- |
| **R** | Responsible (실행) | 실제로 일을 수행하는 주체 (여러 조직 가능) |
| **A** | Accountable (최종책임) | 결과를 책임지고 승인하는 주체 (**업무당 1개 조직만**) |
| **C** | Consulted (협의) | 수행 전/중에 의견을 묻는 주체 |
| **I** | Informed (보고) | 결과를 통보받는 주체 |

조직 코드: **A** = 〈발주/운영사〉, **B** = 〈시공/설비사〉, **C** = 〈시운전/계측팀〉

## 주요 업무 RACI (예시 — 검토 후 확정)

| 업무 | 조직 A | 조직 B | 조직 C |
| --- | --- | --- | --- |
| 시운전 절차서 작성·승인 | A | C | R |
| 안전계획·작업허가 관리 | A | R | C |
| 설비 설치·시공 | I | R/A | C |
| 설치 완료 확인·펀치 제기 | C | R | R |
| 단독시운전 수행 | I | C | R/A |
| 인터락·보호 시험 | I | C | R/A |
| 통합시운전 수행 | C | C | R/A |
| 비상정지·안전시험 | A | C | R |
| 성능시험·KPI 측정 | A | C | R |
| 결함(펀치) 조치 | I | R/A | C |
| 펀치리스트 관리·종결 확인 | A | C | R |
| **Go/No-Go 게이트 판정** | **A** | C | C |
| 일일보고 작성 | I | C | R/A |
| 문서·성적서 취합 | C | C | R/A |
| 최종 인수·운영 인계 | R/A | C | C |

> **주의:** 각 행에 **A(최종책임)는 1개 조직만** 두는 것이 원칙입니다. 위 예시에서 `R/A` 는 "그 조직이 수행하면서 최종책임도 진다"는 뜻입니다. 실제 계약·역할에 맞게 조정하세요.

## 담당자 지정 (연락처)

| 설치/시공 책임자 | 〈B〉 | 〈이름〉 | 〈연락처〉 |
| 안전 담당 | 〈 〉 | 〈이름〉 | 〈연락처〉 |
| 품질/문서 담당 | 〈 〉 | 〈이름〉 | 〈연락처〉 |

## 사용 규칙

- 업무가 추가되면 이 표에 행을 추가하고, 반드시 **A를 한 곳**으로 지정합니다.
- 분쟁이 생기면 해당 업무의 **A 조직**이 최종 결정합니다.
- RACI 변경은 PR로 올려 3개 조직이 합의 후 반영합니다.
