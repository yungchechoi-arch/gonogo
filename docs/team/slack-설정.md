# Slack 채널 구성안 (ruya 시운전)

> 3개 역할(테크니션 / 슈퍼바이저 / 엔지니어링) · 10명 이내 소규모 시운전 팀을 위한 Slack 채널 구조, 명명 규칙, 운영 규칙, 온보딩 체크리스트입니다. **과하게 쪼개지 말고 아래 채널로 시작**하세요.

## 1. 명명 규칙

- 모든 채널은 `#ruya-` 접두사로 시작합니다. (프로젝트 식별용)
- 채널명은 **소문자 한글/영문 + 하이픈**. 예: `#ruya-일일보고`
- 역할별 채널이 꼭 필요하면 `#ruya-엔지니어링` 처럼 역할명을 붙입니다.

## 2. 채널 구조

소규모라서 공용 채널 중심으로 운영하고, 채널마다 **오너(관리/진행 책임) 역할**을 둡니다.

| 채널 | 목적 | 오너/모더레이터 | 참여자 | 비고 |
| --- | --- | --- | --- | --- |
| `#ruya-공지` | 전체 공지·일정·결정사항 | **슈퍼바이저** | 전원 | 쓰기는 슈퍼바이저 중심, 읽기 전용에 가깝게 |
| `#ruya-시운전` | 시운전 진행 전반 논의(메인 작업 채널) | **슈퍼바이저**(진행), **테크니션**(현장 실행 공유) | 전원 | 가장 활발한 채널 |
| `#ruya-일일보고` | 일일 시운전 보고 게시·취합 | **슈퍼바이저**(취합) | 전원 | 보고 1건 = 스레드 1개, 테크니션이 현장 내용 작성 |
| `#ruya-이슈펀치` | 결함/펀치리스트 제기·조치 논의 | **엔지니어링**(등록·추적·종결) | 전원 | 펀치 1건 = 스레드 1개, 테크니션이 이상 1차 보고 |
| `#ruya-안전` | 안전사항·작업허가(PTW)·LOTO·위험요인 | **슈퍼바이저** | 전원 | 안전 관련은 반드시 여기 |
| `#ruya-판정` | Go/No-Go 게이트 판정 소통·서명 조율 | **슈퍼바이저**(주관) | 전원 | 게이트 임박 시만 활성, 엔지니어링 기술판정·테크니션 현장확인 공유 |
| `#ruya-엔지니어링` (선택) | 설계 검토·변경·디자인·기술 검토 | **엔지니어링** | 엔지니어링 + 필요 인원 | 전용 채널 대신 `#ruya-시운전` 내 스레드로 운영해도 무방 |

> 소규모에서는 `#ruya-엔지니어링` 을 별도로 만들기보다 `#ruya-시운전` / `#ruya-이슈펀치` 안의 스레드로 설계·기술 논의를 모으는 편이 가볍습니다. 트래픽이 많아지면 그때 분리하세요.

### 선택: Claude 작업 채널

Claude(봇)와의 협업은 현재 Slack DM에서 진행 중입니다. 팀 전체가 결과를 공유하려면 `#ruya-claude` 같은 채널을 별도로 두고 작업 요청/PR 링크를 모을 수 있습니다. (자세한 사용법은 [claude-슬랙-사용가이드.md](claude-슬랙-사용가이드.md) 참고)

## 3. 운영 규칙

### 핀(고정) 규칙

각 채널 상단에 다음을 핀으로 고정합니다.

| 채널 | 고정할 것 |
| --- | --- |
| `#ruya-공지` | 전체 일정표, 비상연락망, 현장 출입 안내 |
| `#ruya-시운전` | 로드맵 링크, 금주 목표 |
| `#ruya-일일보고` | 일일보고 템플릿 링크 |
| `#ruya-이슈펀치` | 펀치리스트(또는 링크), 심각도 기준 |
| `#ruya-안전` | 비상대응 절차, 작업허가 양식 |
| `#ruya-판정` | Go/No-Go 체크리스트 링크 |

### 스레드 사용

- **답변·토론은 반드시 스레드**에서. 채널 본문은 "새 주제 1건 = 메시지 1건".
- 일일보고/펀치/판정은 **항목 1건 = 스레드 1개**로 관리해 이력이 흩어지지 않게 합니다.
- 중요한 결론은 스레드 안에만 두지 말고 `또한 채널에도 전송` 하거나 핀으로 올립니다.

### 알림 규칙 (각자 설정)

| 채널 | 권장 알림 |
| --- | --- |
| `#ruya-공지`, `#ruya-안전`, `#ruya-판정` | 전체 메시지 알림 |
| `#ruya-시운전`, `#ruya-이슈펀치` | @멘션·키워드 알림 |
| `#ruya-일일보고`, `#ruya-엔지니어링` | 하이라이트만 |

- `@here` 는 지금 당장 볼 사람에게, `@channel` 은 전원이 반드시 봐야 할 때만.
- 현장 근무시간 외 알림은 안전/긴급 건에 한합니다. (팀 합의로 시간대 정하기: 〈예: 07:00~19:00〉)
