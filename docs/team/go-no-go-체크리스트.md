# Go / No-Go 체크리스트 — 시운전 판정 게이트 (ruya)

> **이 저장소의 핵심 문서.** 시운전 각 단계로 넘어가기 전, 세 역할(테크니션 / 슈퍼바이저 / 엔지니어링)이 함께 판정 항목을 확인하고 **Go / 조건부 Go / No-Go** 를 서명으로 기록합니다. 게이트마다 아래 양식을 복사해 작성·보관하세요. `〈...〉` 는 채워 넣습니다.
>
> **역할별 판정 책임:** **슈퍼바이저**가 판정 회의를 **주관·승인**하고, **엔지니어링**이 펀치·설계 근거로 **기술 판정**을 하며, **테크니션**이 **현장 확인**을 담당합니다.

## 1. 판정 원칙

| 결론 | 의미 | 조건 |
| --- | --- | --- |
| **Go** | 다음 단계 진입 승인 | 모든 필수 항목 충족, **치명 결함 0** |
| **조건부 Go** | 조건 이행 전제로 진입 허용 | 중/경 결함에 한함, 기한·담당 명시, **슈퍼바이저 승인** |
| **No-Go** | 진입 불가, 보완 후 재판정 | 필수 항목 미충족 또는 치명 결함 존재 |

**철칙:** 치명(Critical) 펀치가 하나라도 `open` 이면 무조건 **No-Go**. (→ [펀치리스트](templates/펀치리스트-템플릿.md), 엔지니어링 관리)

## 2. 게이트 개요

5단계 흐름: **설치완료 → 단독시운전 → 통합시운전 → 성능시험 → 인수**. 각 게이트는 **슈퍼바이저 주관**, **엔지니어링 기술판정**, **테크니션 현장확인**으로 판정합니다.

| 게이트 | 판정 시점 | 다음 단계 | 주관 / 판정 |
| --- | --- | --- | --- |
| **게이트 1 (설치완료)** | 설치완료 후 | 단독시운전 | 슈퍼바이저 주관 / 엔지니어링 기술판정 / 테크니션 현장확인 |
| **게이트 2 (단독시운전)** | 단독시운전 후 | 통합시운전 | 슈퍼바이저 주관 / 엔지니어링 기술판정 / 테크니션 현장확인 |
| **게이트 3 (통합시운전)** | 통합시운전 후 | 성능시험 | 슈퍼바이저 주관 / 엔지니어링 기술판정 / 테크니션 현장확인 |
| **게이트 4 (성능시험)** | 성능시험 후 | 인수 | 슈퍼바이저 주관 / 엔지니어링 기술판정 / 테크니션 현장확인 |
| **게이트 5 (인수)** | 인수 준비 완료 후 | 운영 인계(최종) | 슈퍼바이저 주관 / 엔지니어링 기술판정 / 테크니션 현장확인 |

## 4. 운영 규칙

- 게이트별 판정은 **반드시 세 역할 공동**으로, 서명을 남깁니다. (서명란 공란이면 미판정으로 간주)
- 판정 회의는 **슈퍼바이저**가 주관하고, **엔지니어링**이 펀치·설계 근거로 기술판정, **테크니션**이 현장 확인을 수행합니다.
- **조건부 Go** 는 조건(내용·담당·기한)을 명시해야 성립합니다. 조건 미이행 시 다음 게이트에서 재검토합니다.
- 판정 회의는 [회의록 템플릿](templates/회의록-템플릿.md) 으로 남기고, 결과를 이 문서의 "판정 이력" 에 반영합니다.
- 판정 근거(성적서·펀치 현황 등)는 링크 또는 파일로 첨부합니다.
